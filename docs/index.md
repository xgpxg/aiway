# 简介

**aiway** (API and AI Gateway) 是一个基于 Rust 构建的高性能 API + AI 网关。

凭借 Rust 的内存安全特性和零成本抽象，aiway 在保证高性能的同时提供卓越的安全性和稳定性。无需复杂配置和环境依赖，网关节点可动态扩容/缩容，轻松应对百万并发连接。

## 核心能力

作为API网关：

- 动态路由：灵活配置请求路由规则，支持域名、路径、请求头、参数等规则匹配

- 服务管理：统一管理后端服务实例，支持健康检查

- 域名管理：支持动态添加、删除、修改域名，支持 TLS 证书管理以及TLS终止

- 插件系统：基于 WASM 的可扩展插件架构，支持热加载

- 安全防护：内置API Key验证、防火墙、IP 黑/白名单、Referer 校验等

- 日志监控：完整的日志存储与监控，支持异常通知提醒

- 控制台：可视化的配置操作，无需编写复杂的配置文件

- 简单轻量：零环境依赖，无需Docker/K8S环境，裸机运行

作为AI网关：

- AI 模型代理：智能 AI 模型代理与请求转发

- MCP 集成：支持MCP托管和自定义MCP服务，支持将存量HTTP接口转为MCP服务

## 支持的协议

- HTTP (IPv4/IPv6)
- SSE
- WebSocket
- MCP

## 支持的平台

通用系统：

- Linux (x86_64 / arm64)
- macOS (arm64)

国产化系统：

- openEuler (x86_64)
- UOS Server (x86_64)
- KylinOS (x86_64)
