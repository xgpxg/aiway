# L4 透传

Access 层采用 L4（传输层）TCP 代理模式，无需解析 HTTP 协议。

## 架构

```
客户端 → Access(:7080) → 网关节点(:7001)
```

## 节点发现

1. Access 启动时从控制台拉取在线网关节点列表
2. 每 5 秒刷新一次节点列表
3. 新连接轮询选择一个可用节点

## 数据转发

- 使用 `tokio::io::copy` 进行双向数据复制
- 客户端往服务端方向
- 服务端往客户端方向
- 任意方向断开即终止连接

## 部署位置

Access 层应部署在网络边界，可直接对客户端暴露。多 Access 实例可水平扩展。
