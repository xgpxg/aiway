# 网关服务

网关是 aiway 的核心组件，基于 [Pingora](https://github.com/cloudflare/pingora) 框架构建，负责请求代理、路由转发、负载均衡、鉴权认证和插件执行。

## 架构

网关内部通过 Pingora 的 `ProxyHttp` trait 实现完整的 HTTP 代理生命周期。每个请求经过一系列处理阶段后转发到后端服务。

## 核心能力

- **动态路由**：基于域名 + 方法 + 路径的多维度路由匹配
- **负载均衡**：支持后端服务实例的自动发现和轮询分发
- **鉴权认证**：Bearer Token (API Key) 认证
- **防火墙**：IP 黑/白名单、Referer 校验
- **插件系统**：全局 + 路由级 WASM 插件，请求/响应阶段均可介入
- **AI 模型代理**：将 AI 模型请求转发到不同供应商
- **MCP 集成**：Model Context Protocol 代理
- **请求日志**：完整的请求/响应日志记录（含 IP 地理信息）
- **监控指标**：请求计数、连接数、响应时间等实时统计
- **告警通知**：网关异常时自动推送告警

## 启动

```bash
./gateway --address 0.0.0.0 --port 7001 --console 127.0.0.1:7000
```

网关启动后会连接 Console 拉取配置，订阅配置变更后自动热更新，无需重启。
