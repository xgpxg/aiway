# 插件系统

网关插件基于 WASM（WebAssembly）技术，提供安全、可扩展的插件机制。

## 插件类型

| 类型 | 作用范围 | 说明 |
|------|----------|------|
| 全局插件 | 所有请求 | 在每个请求的所有阶段执行 |
| 路由插件 | 特定路由 | 仅在该路由匹配时执行 |
| 模型插件 | AI 模型供应商 | 仅在该模型的请求中执行 |

## 插件生命周期

| 阶段 | 执行时机 | 操作对象 |
|------|----------|----------|
| `on_request` | 请求转发前 | 请求头 |
| `on_request_body` | 请求转发前 | 请求体 |
| `on_response` | 收到响应后 | 响应头 |
| `on_response_body` | 收到响应后（同步） | 响应体 |
| `on_logging` | 日志记录时 | 上下文 |

## 插件开发

插件使用 WASM 编译，语言不限（推荐 Rust）。参考 [插件开发](../plugins/overview.md) 文档。

## 配置同步

插件的增删改查通过控制台管理，变更后自动同步到网关节点。
