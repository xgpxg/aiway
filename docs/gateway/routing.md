# 路由

路由是网关的核心功能，决定请求如何分发到后端服务。

## 匹配规则

路由匹配基于三个维度：

- **域名 (Host)**：精确匹配
- **HTTP 方法**：GET、POST、PUT、DELETE 等
- **路径 (Path)**：支持精确路径匹配

匹配时域名会自动去除端口号。

## 路由配置

在控制台的路由管理页面配置，包含：

| 配置项 | 说明 |
|--------|------|
| 基本信息 | 名称、描述 |
| 域名 | 匹配的 Host |
| 路径 | 请求路径 |
| 目标服务 | 路由指向的后端服务 |
| 鉴权开关 | 是否开启 API Key 认证 |
| 白名单 | 跳过鉴权的路径列表 |
| 插件配置 | 该路由关联的插件 |

## 配置同步

配置变更流程：

1. 在控制台修改路由配置
2. 控制台将配置写入数据库
3. 网关定期从控制台拉取最新配置
4. 网关热加载新路由规则，无需重启

## 未匹配处理

未匹配到任何路由的请求返回 `404 Not Found`。
