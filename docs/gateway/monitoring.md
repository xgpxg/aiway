# 监控与告警

## 实时监控

网关内置监控模块，实时统计以下指标：

| 指标            | 说明                |
|---------------|-------------------|
| 请求总数          | 累计请求数量            |
| 无效请求数         | 被防火墙拦截的数量         |
| HTTP 连接数      | 当前活跃 HTTP 连接      |
| SSE 连接数       | 当前活跃 SSE 连接       |
| WebSocket 连接数 | 当前活跃 WebSocket 连接 |
| 各状态码计数        | 按 HTTP 状态码统计      |
| 平均响应时间        | 请求处理平均耗时          |

监控数据通过 HTTP API 上报到控制台，在仪表盘展示。

## 告警

告警模块支持自定义通知：

- 网关节点 Panic 时自动告警
- 网关代理错误（502）时告警
- 通过控制台配置告警通知方式

## Panic 恢复

网关设置全局 panic hook，发生 panic 时：

1. 记录错误日志
2. 触发告警通知
3. 修正连接计数
4. 恢复继续运行
